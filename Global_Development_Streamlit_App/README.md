# Global Development Clustering Streamlit App

## Overview
This Streamlit application clusters countries based on development indicators using:
- K-Means
- Hierarchical Clustering
- DBSCAN

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py

Make sure the dataset file:
World_development_mesurement.xlsx

is placed in the same directory as app.py.
